# 🦷 Dental Clinic

A full-stack dental clinic appointment booking system built with **Laravel, React, and MySQL**.

The platform allows patients to book appointments online, while administrators can manage appointments and access patient information through an admin interface.

## 🚀 Features

### 👤 Patients

* Register and login
* Email verification
* Book dental appointments
* View their appointments
* Manage their account

### 🔐 Admin

* Secure admin access
* View and manage appointments
* Access patient information
* Manage the clinic's booking system

## 🛠️ Technologies

* **Backend:** Laravel
* **Frontend:** React.js
* **Database:** MySQL
* **Authentication:** Laravel Sanctum
* **Email Verification:** Laravel
* **CI/CD:** GitHub Actions
* **API:** REST API

## 🔄 CI/CD

The project includes a **GitHub Actions CI/CD workflow** to automate testing and ensure the application is properly validated before deployment.

## 🎯 Project Goal

The goal of this project is to provide a simple and efficient digital solution for dental clinics, allowing patients to book appointments online while giving administrators centralized access to manage bookings and patient information.
